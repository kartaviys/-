# Заглушка для переезда Мнемо

Веб-версия Мнемо переехала:

- старый адрес: https://kartaviyukr.github.io/-/mnemo/
- новый адрес: **https://kartaviys.github.io/-/mnemo/**

Этот репозиторий нужен только для старого адреса. Страница `mnemo/index.html` читает прогресс
(`mnemo.v1`, `mnemo.photos2`) из памяти браузера на старом адресе и передаёт его на новый адрес
через `https://kartaviys.github.io/-/mnemo/move.html#…`. Данные идут после `#`, поэтому на сервер они не уходят.
Если прогресса нет или он уже перенесён, страница сразу открывает новый адрес.

GitHub Pages: Deploy from a branch → `main`, папка `/ (root)`.
