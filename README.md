# ЕГЭ Квест: подготовка к ЕГЭ по русскому языку

Игровое приложение для подготовки к ЕГЭ: дорога к Замку Грамотности (26 тестовых заданий + сочинение), опыт и уровни, монеты, свой город, достижения, комбо и сундуки.

Сейчас готово **задание 17** (обособленные определения и обстоятельства):
алгоритм-интеллект-карта с «приближением» каждого шага → пошаговая разметка первого предложения
(основы разными цветами, подлежащее одной чертой, сказуемое двумя, определение волнистой, обстоятельство точкой-тире,
главное слово ×, стрелки, границы |) с проверкой → самостоятельное испытание на втором предложении с проверкой в конце.

## Как это работает на iPhone и Android

Приложение сделано как **PWA** (устанавливаемое веб-приложение): один код для обеих платформ, App Store и Google Play не нужны,
после первого открытия работает без интернета, прогресс хранится на устройстве.

- **iPhone / iPad:** открыть ссылку в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android:** открыть ссылку в Chrome → «Установить приложение» (или ⋮ → «Добавить на главный экран»).

## Подписка MAGISTER: коды активации

Оплата пока не подключена. После оплаты ученику выдаётся код вида `MAG-XXXX-XXXX`, он вводит его в «Профиль → MAGISTER».
Новые коды печатает генератор (он не выкладывается на сайт):

```bash
node tools/magister-codes.mjs 10
```

Код проверяется на телефоне, без сервера, поэтому это защита «от честных людей». Когда понадобится настоящая оплата,
нужны аккаунт в платёжной системе и небольшой сервер для проверки платежей.

## Локальный запуск

```bash
python3 -m http.server 8000 --directory app
```

Затем открыть http://localhost:8000.

## Структура

- `app/index.html`: оболочка приложения
- `app/js/app.js`: состояние, награды, карта пути, город, профиль, движок уроков
- `app/js/markup.js`: движок разметки предложения и проверки
- `app/js/world.js`: башня мага, книга заклинаний, мини-игры, ежедневные миссии, MAGISTER
- `app/js/task1.js`: урок по заданию 1
- `app/js/task17.js`: урок по заданию 17 (новые задания добавляются так же: `App.LESSONS[n] = { slides }`)
- `app/css/style.css`: оформление (белый фон, фиолетовый и жёлтый)
- `app/sw.js`, `app/manifest.webmanifest`: офлайн-режим и установка
