# ТехПульс — технические новости ИИ без хайпа (Android)

Приложение само обходит ~30 источников (исследовательские и инженерные блоги, arXiv, Hacker News,
Reddit, Lobsters, Хабр), собирает свежие статьи и **отсеивает нетехнический шум**:
«глава OpenAI заявил», «ИИ захватит мир», акции и раунды инвестиций, суды, политику, драмы.

## Установка

1. Откройте на телефоне страницу **Releases** этого репозитория и скачайте последний `TechPulse.apk`.
2. Разрешите установку из неизвестных источников, установите.
3. Новые версии ставятся поверх старой (все сборки подписаны одним ключом).

APK собирается автоматически GitHub Actions при каждом изменении в `tech-news-android/`
(workflow `.github/workflows/techpulse-android.yml`), его также можно запустить вручную во вкладке Actions.

## Как работает фильтр

Каждая статья получает оценку (`filter/TechFilter.kt`):

| Плюсы | Минусы |
|---|---|
| arXiv/статьи, technical report, бенчмарки (SWE-bench, MMLU…), датасеты | «CEO/глава/Альтман/Маск … заявил/предупредил» (−6) |
| fine-tuning, RLHF/DPO/GRPO, квантизация, дистилляция, LoRA, MoE | страшилки: апокалипсис, «захватит мир», «заменит программистов» |
| инференс: KV-cache, speculative decoding, vLLM, llama.cpp | акции, инвестиции, оценка компании, IPO |
| CUDA/Triton, GPU/TPU, архитектуры, интерпретируемость | суды, регулирование, политика, увольнения, скандалы |
| «deep dive», «под капотом», «с нуля», «как мы сделали», ссылки на GitHub/HF/arXiv | бизнес- и жёлтые СМИ (CNBC, Forbes, Futurism…) |

Заголовок весит больше описания. Порог («строгость») настраивается ползунком; можно добавить свои
интересные слова и стоп-слова. На любой карточке «⋮ → Почему показано?» показывает разбор оценки.
Отсеянное можно показать полупрозрачным, чтобы проверить фильтр.

## Возможности

- Лента с фильтрами по разделам (Исследования, Инженерия, Сообщество, Технологии, На русском) и по темам (#LLM, #Инференс, #Железо…)
- Сортировка «Новые» / «Лучшие» (по технической оценке за 3 дня), поиск
- Избранное, отметка прочитанного, склейка дублей (одна статья с arXiv, HN и блога — одна карточка)
- «Открыть с переводом на русский» (через Google Translate), ссылка на обсуждение HN
- Управление источниками: вкл/выкл, статус загрузки, добавление своих RSS/Atom
- Фоновое обновление (1–24 ч) и уведомления о новых технических статьях

## Сборка локально

Нужны JDK 17 и Android SDK:

```bash
cd tech-news-android
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest # тесты фильтра
```

Стек: Kotlin, Jetpack Compose (Material 3), OkHttp, WorkManager. Без бэкенда и аккаунтов — всё на телефоне.
