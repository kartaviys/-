# Автоотклик на hh.ru — Python-версия (для компьютера)

Упрощённый вариант для компьютера: отклики на hh.ru **через официальный API** (нужно одобренное приложение
на dev.hh.ru) плюс заполнение анкет работодателей в браузере (Playwright).

> Основной вариант — **[Android-приложение](../android/README.md)**: там агенты hh, Хабр Карьеры, LinkedIn и ещё
> 22 сайтов работают через сайты (API hh не нужен), проверяют каждую вакансию нейросетью и ведут учёт расходов.
> В Python-версии этого нет — только API hh и фильтр по названию.

## Что делает

1. Ищет вакансии на hh **по названию** по вашим запросам (простые запросы, по одному: data scientist, ml engineer…),
   без фильтров по региону, опыту и дате (их можно включить в `config.toml`).
2. Отсекает по названию: junior/стажёры, lead/head, компьютерное зрение, Data Engineer / инженер данных, DWH/ETL, BI,
   бизнес- и системные аналитики, DevOps/MLOps, backend/frontend, QA; а также вакансии, где в описании много CV.
3. Определяет язык вакансии и пишет сопроводительное: на английском — с английским резюме, на русском — живое письмо
   по фактам из резюме.
4. Откликается через API hh (резюме нужного языка из вашего профиля).
5. Вакансии с **тестом** или откликом **на сайте работодателя** открывает в браузере и заполняет анкету: письмо,
   контакты, ответы, файл резюме. На **любой вопрос о зарплате — `250000`** (`salary_answer`).
6. Записывает всё в `applications.db`, чтобы не откликаться дважды; `journal` показывает журнал.

## Нейросеть

Claude (по умолчанию — Claude Haiku 5.5) и/или DeepSeek. Ключи — через переменные окружения:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

```bash
export DEEPSEEK_API_KEY=sk-...
```

В `[llm]`: `providers = ["claude", "deepseek"]` — первый основной, второй запасной; `strategy = "round_robin"` —
по очереди. Одно письмо на Claude Haiku ≈ $0.0006, на DeepSeek ≈ $0.0012.

## Настройка

1. **Приложение hh.ru:** зарегистрируйте на https://dev.hh.ru/admin и впишите в `config.toml` `client_id`,
   `client_secret`, `redirect_uri`.
2. **Авторизация:** `python -m hh_autoapply auth` → открыть ссылку → вставить `code` из адреса.
3. **Резюме:** создайте на hh.ru второе резюме на английском, выполните `python -m hh_autoapply resumes` и впишите
   id в `ru_resume_id` и `en_resume_id`.
4. **Файлы резюме:** `resumes/resume_ru.pdf` и `resumes/resume_en.pdf` — факты для писем и файл для анкет.
5. **Вход на hh.ru в браузере (для тестов):** `python -m hh_autoapply login` → войти → Enter.
6. Раздел `[profile]`: имя, почта, телефон для анкет.

> API hh не умеет прикладывать файл к отклику — отправляется резюме из профиля. Поэтому для англоязычных вакансий
> нужно английское резюме на hh. `en_cv_url` (публичная ссылка на PDF) добавится в конец английского письма.

## Запуск

Пробный прогон — только письма, без отправки:

```bash
python -m hh_autoapply run --dry-run --limit 5
```

Журнал откликов с текстами писем:

```bash
python -m hh_autoapply journal --letters
```

Реальные отклики:

```bash
python -m hh_autoapply run --live
```

`auto_submit = false` (по умолчанию): бот заполняет анкету на сайте работодателя, вы проверяете и жмёте «Отправить».
Капчу и регистрацию бот не проходит — ждёт вас или (в `headless`) пропускает вакансию.

Ежедневно по расписанию (crontab, 10:00; поставьте `headless = true` и `ask_human = false`):

```
0 10 * * * cd /путь/к/hh_autoapply && .venv/bin/python -m hh_autoapply run --live >> run.log 2>&1
```

## Лимиты и риски

- По умолчанию 150 откликов за запуск и в сутки (у hh максимум 200), пауза 10–30 секунд.
- Массовые автоотклики противоречат правилам hh — держите паузы и разумные лимиты.
- Новые приложения на dev.hh.ru проходят модерацию; без одобрения поиск работает, а отклик вернёт ошибку.
  В таком случае используйте Android-приложение — там hh работает через сайт.
