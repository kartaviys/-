# Автоотклик на hh.ru (Senior Data Scientist / ML Engineer / Data Analyst)

Что делает скрипт:

1. Ищет вакансии уровня Senior по вашим запросам и отбрасывает junior и стажировки.
2. Определяет язык вакансии:
   - для **английской** пишет сопроводительное на английском и откликается английским резюме;
   - для **русской** пишет живое письмо на русском («зацепила вакансия, потому что…»).
3. Откликается через API hh.ru.
4. Если у вакансии **тест/опрос** или отклик идёт **на сайте работодателя**, открывает браузер и
   заполняет анкету: письмо, контакты, ответы на вопросы, файл резюме. На **любой вопрос про
   зарплату отвечает `25000`** (меняется в `salary_answer`).
5. Записывает все отклики в `applications.db`, чтобы не откликаться на одну вакансию дважды.

## Нейросеть: DeepSeek или Claude, или обе вперемешку

Сопроводительное занимает примерно 3,5 тыс. токенов на вход (резюме и вакансия) и 0,5 тыс. на выход.

| Модель | Цена за 1M токенов (вход / выход) | 1 письмо | 200 писем |
|---|---|---|---|
| Claude Haiku 5.5 | $0.10 / $0.50 | ≈ $0.0006 | ≈ $0.12 |
| DeepSeek (deepseek-chat) | ≈ $0.28 / $0.42 * | ≈ $0.0012 | ≈ $0.24 |

\* Цены DeepSeek могут меняться, актуальные — на api-docs.deepseek.com. Анкета на сайте
работодателя стоит ещё один такой же запрос.

Обе модели обходятся в копейки. В `[llm]` можно выбрать:
- `providers = ["claude", "deepseek"]` и `strategy = "fallback"` (по умолчанию): всегда Claude Haiku, а DeepSeek только при ошибке;
- `strategy = "round_robin"`: модели по очереди (вперемешку), удобно сравнить качество писем;
- `providers = ["deepseek"]`: только DeepSeek, ключ Claude не нужен.

Ключи передаются через переменные окружения, в файлы их не кладите:

```bash
export DEEPSEEK_API_KEY=sk-...
```

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

## Настройка

1. **Приложение hh.ru.** Зарегистрируйте его на https://dev.hh.ru/admin и впишите в
   `config.toml` значения `client_id`, `client_secret` и `redirect_uri`.
2. **Авторизация:** выполните `python -m hh_autoapply auth`, откройте ссылку и вставьте `code` из адреса.
3. **Резюме на hh.ru.** Создайте в профиле второе резюме на английском. Выполните
   `python -m hh_autoapply resumes` и впишите оба id в `ru_resume_id` и `en_resume_id`.
4. **Файлы резюме.** Положите их в `resumes/resume_ru.pdf` и `resumes/resume_en.pdf`.
   Из них берутся факты для писем, и они же прикрепляются к анкетам на сайтах.
5. **Вход в hh.ru в браузере (для тестов):** выполните `python -m hh_autoapply login`,
   войдите в открывшемся окне и нажмите Enter.
6. Заполните раздел `[profile]`: имя, почта, телефон для анкет.

> Почему английское резюме нужно и на hh.ru: API hh не умеет прикладывать файл к отклику,
> он отправляет одно из резюме вашего профиля. Поэтому для англоязычных вакансий
> откликается английское резюме с hh. Если укажете `en_cv_url` (публичную ссылку на PDF),
> она добавится в конец английского письма. На сайтах работодателей PDF загружается напрямую.

## Запуск

Сначала пробный прогон: скрипт только покажет письма и ничего не отправит.

```bash
python -m hh_autoapply run --dry-run --limit 5
```

Журнал всех откликов (с текстами писем):

```bash
python -m hh_autoapply journal --letters
```

Когда письма понравятся, запустите реальные отклики:

```bash
python -m hh_autoapply run --live
```

По умолчанию `auto_submit = false`: бот заполняет анкету на стороннем сайте, а вы проверяете
и сами жмёте «Отправить». Когда убедитесь, что анкеты заполняются правильно, можно
поставить `auto_submit = true`. Капчу и регистрацию на сайте бот не проходит: он ждёт вас
или пропускает вакансию, если включён режим `headless`.

Для запуска каждый день по расписанию (crontab, в 10:00):

```
0 10 * * * cd /путь/к/hh_autoapply && .venv/bin/python -m hh_autoapply run --live >> run.log 2>&1
```

Для запуска по расписанию поставьте `headless = true` и `ask_human = false`. Вакансии, где нужен
человек, получат статус `manual`.

## Ограничения и риски

- У hh лимит 200 откликов в сутки; скрипт останавливается на `daily_limit`.
- Массовые автоотклики, особенно через браузер, противоречат правилам hh.ru. За них могут
  ограничить аккаунт, поэтому держите паузы (`delay_seconds`) и разумный `max_applications`.
- Новые приложения на dev.hh.ru проходят модерацию. Пока доступа к откликам через API нет,
  поиск работает, а отклик вернёт ошибку.
