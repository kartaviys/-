Положите сюда свои резюме (PDF, DOCX или TXT):

- `resume_ru.pdf` — русское резюме;
- `resume_en.pdf` — английское резюме.

Нейросеть берёт из них факты для сопроводительных писем. Этот же файл прикрепляется
к анкетам на сайтах работодателей, если там есть поле загрузки CV.

Если не хотите хранить резюме в репозитории, держите файлы только локально и не коммитьте их.
