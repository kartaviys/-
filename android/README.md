# HH Автоотклик для Android

## Установка

Скачайте APK на телефон и откройте файл:
https://github.com/kartaviyukr/-/releases/download/hh-autoapply-latest/hh-autoapply.apk

Android попросит разрешить установку из этого источника: разрешите. APK собирается
автоматически (GitHub Actions, workflow «HH Автоотклик APK») при каждом пуше в `android/`.

## Первая настройка (по порядку)

1. **Настройки → Нейросеть**: вставьте ключ Claude (`sk-ant-…`, берётся на console.anthropic.com).
   По умолчанию используется дешёвая модель `claude-haiku-5-5`. Ключ DeepSeek можно добавить как запасной.
2. **Настройки → hh.ru API**: Client ID, Client Secret и Redirect URI вашего приложения с https://dev.hh.ru/admin.
   В приложении на dev.hh.ru укажите тот же Redirect URI (по умолчанию `https://localhost/hh-autoapply`).
3. Кнопка **«Войти через API hh»**: разрешите доступ, и токен сохранится.
4. Кнопка **«Мои резюме на hh»**: выберите резюме для русских, а затем для английских вакансий.
5. Кнопки **«PDF резюме RU / EN»**: выберите файлы. Claude один раз прочитает их в текст для писем,
   а PDF будет прикрепляться к анкетам на сайтах работодателей.
6. Кнопка **«Войти на hh.ru (для тестов)»**: войдите в аккаунт во встроенном браузере.
7. **Настройки → Профиль**: имя, почта, телефон для анкет.

## Работа

- **«Журнал»**: все отклики с фильтрами (отправленные, пробные, ждут анкету, ошибки), текстом письма и ссылкой на вакансию.
- **«Пробный прогон»**: находит вакансии и пишет письма, но ничего не отправляет. Письма видны в логе и в «Журнале».
- **«Откликнуться»**: настоящие отклики через API hh. Работает в фоне, даже при выключенном экране.
- Вакансии с **тестом** или откликом **на сайте работодателя** попадают в очередь **«Анкеты»**.
  Там встроенный браузер открывает форму, и нейросеть заполняет поля. На вопросы о зарплате всегда
  ставится значение из настроек (25000). Резюме прикрепляется при тапе на поле загрузки файла.
  Проверьте анкету, отправьте её и нажмите «Отправлено ✓».
- **Настройки → «Откликаться автоматически каждый день»** включает ежедневный запуск в заданный час.

## Источники вакансий

Кнопка **«Источники вакансий»** на главном экране открывает список площадок. У каждой есть переключатель «вкл/выкл»,
кнопка **«Инструкция»** (как подключить) и **«Открыть»**.

- 🤖 **hh.ru** — поиск и отклик полностью автоматически через API.
- 📥 **Авто-сбор** (Хабр Карьера, GetMatch, Trudvsem, Telegram-каналы, Hacker News «Who is hiring», Remote OK,
  We Work Remotely, Remotive, Himalayas) — вакансии собираются при каждом запуске, письмо пишется заранее,
  вакансия попадает в «Анкеты». Там встроенный браузер открывает её, ИИ заполняет форму, вы подтверждаете.
- 🧭 **С подтверждением** (LinkedIn, Indeed, Glassdoor, Levels.fyi, Built In, Dice, Wellfound, Welcome to the Jungle,
  aijobs.net, Arc.dev, Turing, EURES, StepStone, XING, Relocate.me, Landing.jobs, Indeed Italia, InfoJobs.it, SuperJob,
  Работа.ру, Авито Работа, Сетка, GeekJob, ODS, карьерные сайты компаний) — у этих площадок нет открытого API или
  автоматизация запрещена их правилами. «Открыть» → вакансия → **«Отклик с ИИ»**: нейросеть читает вакансию, пишет
  письмо (копирует его) и заполняет форму; вы проверяете, отправляете и жмёте **«В журнал ✓»**.

Запросы для российских и зарубежных площадок, список Telegram-каналов и карьерных сайтов — в
«Настройки → Источники (кроме hh)».

## 🤖 Агент (hh без API и площадки без API)

Пока hh не одобрил приложение, hh работает через сайт. Режим выбирается в «Настройки → hh.ru: режим работы»:
`auto` (по умолчанию) — API, если подключено, иначе сайт; `api`; `site`.

Кнопка **«🤖 Агент»** на главном экране запускает сессию:
1. Проверяет вход на hh.ru (если не вошли — попросит войти прямо в окне).
2. Ищет вакансии на hh.ru по вашим запросам (senior, за N дней), отсеивает лишнее и CV.
3. Для каждой: открывает, пишет письмо, нажимает «Откликнуться», выбирает нужное резюме (RU/EN), вставляет письмо,
   отправляет. Тест от работодателя проходит ИИ-агент.
4. Затем проходит очередь «Анкеты» (Хабр, GetMatch, Telegram, удалёнка): открывает вакансию и откликается сам.

Агент работает, пока экран открыт (экран не гаснет) — запускайте на зарядке. Между откликами — пауза от 15 секунд.
Капчу, вход, SMS-коды, оплату и паспортные данные агент не трогает: показывает «✋» и ждёт «Готово» или «Пропустить».
На LinkedIn перед каждой отправкой всегда спрашивает подтверждение; для остальных — по настройке
«Спрашивать подтверждение перед каждой отправкой».

На площадках «с подтверждением»: «Открыть» → вакансия → **«🤖 Агент»** → «Старт» — агент откликнется на эту вакансию.

Ежедневный автозапуск присылает уведомление «Запустите агента» — нажмите его, и сессия начнётся.

## 🚀 Быстрый старт (минимум шагов, без API)

1. Главный экран → «Быстрый старт» → вставьте ключ нейросети (Claude или DeepSeek) → «Сохранить ключ».
2. «Войти на hh.ru» → войдите в аккаунт → «Готово».
3. «🤖 Запустить агента». Агент сам возьмёт названия и тексты резюме из вашего профиля hh (русское — для русских
   вакансий, английское — для английских), найдёт вакансии и откликнется. Лимит откликов за сессию — поле на экране агента.

Капча: автопроверки вида «Just a moment / Checking your browser» агент просто пережидает; настоящую капчу
решаете вы — агент присылает громкое уведомление «Агенту нужна помощь», тап по нему открывает окно агента.

## Изменения: поток откликов, простые запросы, фон, расходы

- Агент откликается сразу по ходу поиска: запрос → страница → отклики → следующая страница → следующий запрос,
  пока не наберёт лимит.
- Запросы для hh — простые, по одному на строку (data scientist, ml engineer, …). Старые OR-запросы заменяются автоматически.
- Агент работает в фоне и при выключенном экране (фоновая задача с уведомлением). Окно «Агент» — пульт: смотреть, остановить,
  помочь с капчей. На вопрос «нужна помощь» ждёт до 15 минут, потом пропускает вакансию и идёт дальше.
- «💰 Расходы» на главном экране: запросы, токены и деньги по дням и моделям за 14 дней, итоги за 7 и 30 дней.
  «Дневной бюджет на нейросеть» (по умолчанию $1) — при превышении агент останавливается.

## Изменения: обновления без переустановки, рекомендации hh, зарплата 250 000

- Сборки подписываются постоянным ключом (создаётся один раз в CI и хранится в кэше сборки, либо берётся из секретов
  репозитория `HH_KEYSTORE_B64` + `HH_KEYSTORE_PASSWORD`). Новые версии ставятся поверх, входы и настройки сохраняются.
  Один последний раз после этого обновления нужно удалить старую версию.
- Агент сначала проходит вакансии, которые hh рекомендует под ваши резюме («Вакансии для вас»), потом ищет по запросам.
- Поиск без привязки к региону и без фильтра опыта (включаются в «Настройки → Поиск»).
- На любые поля о зарплате — 250 000 (поле «Ответ на любой вопрос про зарплату»).
- Капчу агент не решает сам, но как только вы её решите, продолжает автоматически — нажимать «Готово» не нужно.
