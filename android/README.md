# HH Автоотклик — Android-приложение

Автоматические отклики на вакансии Data Scientist / ML / AI / NLP / Data Analyst уровня senior:
hh.ru, LinkedIn и ещё три десятка площадок. Нейросеть пишет живое сопроводительное письмо под каждую
вакансию (на русском или английском — по языку вакансии), браузерный агент сам нажимает «Откликнуться»,
выбирает нужное резюме, заполняет анкеты и тесты. Всё ведётся в журнале, расходы на нейросеть считаются.

## 1. Установка и обновление

1. Откройте на телефоне ссылку и скачайте APK:
   **https://github.com/kartaviys/-/releases/download/hh-autoapply-latest/hh-autoapply.apk**
2. Откройте файл → Android попросит разрешить установку из этого источника → «Настройки» → включить → назад →
   «Установить».
3. При первом запуске разрешите уведомления — через них приходят итоги и просьбы о помощи (капча, вход).
4. **Отключите экономию батареи** для приложения, иначе Android может усыплять фоновую работу:
   «Настройки телефона → Приложения → HH Автоотклик → Батарея → Без ограничений».

**Обновление.** Новые версии публикуются по той же ссылке. Все сборки подписаны одним ключом, поэтому новая
версия ставится поверх старой — входы в hh/LinkedIn, настройки и журнал сохраняются. (Если Android всё же пишет
«конфликтует с другим пакетом» — удалите старую версию один раз и поставьте заново.)

## 2. Быстрый старт — 3 шага

1. **Ключ нейросети** — вставьте ключ Claude (`sk-ant-…`) или DeepSeek (`sk-…`) → «Сохранить ключ».
   Где взять — [раздел 7](#7-нейросеть-claude-deepseek-своя-модель).
2. **«Войти на hh.ru»** и/или **«Войти в LinkedIn»** → войдите в аккаунт → «Готово». Вход запоминается.
3. **«🤖 Агент hh»** или **«🤖 Агент LinkedIn»** → проверьте список «Что искать» → «Старт».

Совет для первого раза: поставьте **лимит 3–5** на экране агента и посмотрите, как он работает.

## 3. Главный экран

| Блок / кнопка | Что делает |
|---|---|
| 1. Ключ нейросети | Сохранить ключ Claude или DeepSeek |
| 2. hh.ru — «Войти на hh.ru», «🤖 Агент hh» | Вход на hh и пульт агента hh ([раздел 4](#4-агент-hh)) |
| 3. LinkedIn — «Войти в LinkedIn», «🤖 Агент LinkedIn» | Вход в LinkedIn и пульт агента LinkedIn ([раздел 5](#5-агент-linkedin)) |
| Журнал / 💰 Расходы / Настройки | Отклики с письмами, расходы на нейросеть, все настройки |
| Статус | Нейросеть, откликов сегодня, анкет в очереди, расходы, что делает агент |
| ▸ Дополнительно | Другие площадки, PDF резюме, официальный API hh, пробный прогон, «Откликнуться (всё)», «Анкеты», «Стоп всё» |
| Лог | Что происходит прямо сейчас |

## 4. Агент hh

Агент работает с сайтом hh.ru как человек, но сам. Официальный API hh для этого не нужен.

**Что искать** — список прямо на экране агента («✏️ Что искать и лимит»): по одной вакансии на строку, ищется
**только по названию вакансии**, без фильтров по региону, опыту и дате. Список можно редактировать перед каждым
стартом; базовый — data scientist, ml engineer, ml-инженер, AI engineer, NLP, ML-аналитик, аналитик данных и др.

**Порядок работы:**
1. Проверяет вход на hh (если не вошли — попросит).
2. Импортирует резюме из профиля (если тексты ещё не заданы).
3. **Рекомендации hh:** проходит «подходящие вакансии», которые hh подбирает под каждое ваше резюме.
4. **Ваш список «Что искать»** — по одному запросу, по порядку.
5. По каждому запросу проходит **все страницы** результатов (стр. 1, 2, 3, … по 50 вакансий): на каждой сразу
   откликается, потом листает дальше. Останавливается, когда страницы кончились или набран лимит.
   В логе видно: «hh «data scientist», стр. 3: вакансий 50, новых подходящих 12».
6. Затем проходит очередь «Анкеты» с других площадок.

**Как откликается:** открывает вакансию → нейросеть пишет письмо → «Откликнуться» → выбирает резюме нужного
языка → вставляет письмо → поля о зарплате заполняет **250 000** → отправляет. Тест или анкету от работодателя
проходит ИИ: отвечает по резюме.

**Что отсекается:** junior, стажировки, lead/head, компьютерное зрение (по названию и если описание явно про CV),
вакансии в архиве и те, на которые уже откликались.

**Пульт агента:**
- поле **«Лимит откликов за сессию»** (по умолчанию 50);
- «Старт» / «Стоп»;
- окно браузера — видно, что делает агент;
- «Готово» / «Пропустить» — когда агент просит помощи.

**Работает в фоне.** Можно свернуть приложение и выключить экран — в шторке висит уведомление с текущим действием.
Лучше запускать на зарядке.

**Капча.** Автопроверки вида «Checking your browser» агент пережидает сам. Настоящую капчу решаете вы: придёт
громкое уведомление «Агенту нужна помощь» → тап → решите капчу → агент **продолжит сам**, как только она исчезнет.
Если 15 минут никто не ответил — вакансия пропускается, агент идёт дальше.

**Подтверждение перед отправкой** — выключено (агент отправляет сам). Включить: «Настройки → Браузерный агент →
Спрашивать подтверждение».

## 5. Агент LinkedIn

Отдельный агент с теми же возможностями, что у hh, и той же нейросетью. Кнопка **«🤖 Агент LinkedIn»**.

1. Главный экран → «Войти в LinkedIn» → войдите (email и пароль; вход через Google в приложении не работает) → «Готово».
2. «🤖 Агент LinkedIn» → проверьте/отредактируйте **«Что искать»** (свой список, отдельный от hh) → «Старт».
3. Агент работает так же, как на hh: сначала **рекомендованные LinkedIn вакансии** (только с Easy Apply), затем ваш
   список — **все страницы** результатов. Каждую вакансию открывает, пишет письмо и проходит все шаги Easy Apply:
   контакты, резюме, вопросы, отправка.

Если в этот момент работает агент hh, кнопка покажет «Остановить hh и запустить LinkedIn».

Настройки — «Настройки → LinkedIn-агент»:
- запросы, по одному на строку;
- локация: пусто — весь мир; можно указать Germany, European Union, Italy и т.п.;
- только удалёнка (по умолчанию да);
- только Mid-Senior (по умолчанию нет);
- вакансии за N дней.

**Осторожный режим по умолчанию.** LinkedIn запрещает автоматизацию и блокирует за неё аккаунты, поэтому:
- агент **спрашивает подтверждение перед каждой отправкой**;
- не больше **30 откликов в сутки** и 20 за сессию;
- пауза **45–120 секунд** между откликами.

Всё это меняется в настройках. Отключать подтверждение и поднимать лимиты — на свой риск.

LinkedIn-агента можно включить в ежедневный автозапуск: «LinkedIn-агент → Запускать в ежедневном автозапуске».

## 6. Другие площадки и «Анкеты»

«Источники вакансий» — список всех площадок. У каждой есть переключатель, **«Инструкция»** (как подключить)
и **«Открыть»**.

| Тип | Площадки | Как работает |
|---|---|---|
| 🤖 hh.ru | hh.ru | Агент (через сайт) или официальный API |
| 📥 Авто-сбор | Хабр Карьера, GetMatch, Trudvsem, Telegram-каналы, Hacker News «Who is hiring», Remote OK, We Work Remotely, Remotive, Himalayas | При каждом запуске собираются вакансии, пишутся письма, вакансии попадают в «Анкеты». Агент hh проходит эту очередь сам |
| 🧭 С подтверждением | LinkedIn, Indeed, Indeed Italia, Glassdoor, Levels.fyi, Built In, Dice, Wellfound, Welcome to the Jungle, aijobs.net, Arc.dev, Turing, EURES, StepStone, XING, Relocate.me, Landing.jobs, InfoJobs.it, SuperJob, Работа.ру, Авито Работа, Сетка, GeekJob, ODS, карьерные сайты компаний | «Открыть» → найдите вакансию → **«🤖 Агент»** (откликнется на эту вакансию сам) или «Отклик с ИИ» (только письмо + заполнение формы) |

На площадках, где нужно откликаться залогиненным (Хабр, GetMatch и т.д.), войдите один раз через «Открыть».

**«Анкеты»** (главный экран) — та же очередь, только проходите её вы: ИИ заполняет форму, вы проверяете и жмёте
«Отправлено ✓». Кнопка «Письмо» копирует письмо — удобно для Telegram-постов и Hacker News, где откликаются
сообщением или письмом на email.

Списки запросов для российских и зарубежных площадок, Telegram-каналов и карьерных сайтов — в
«Настройки → Источники (кроме hh)». Лимит «новых вакансий за запуск» (40) ограничивает расход на письма.

## 7. Нейросеть: Claude, DeepSeek, своя модель

Нужен хотя бы один вариант.

**Claude (рекомендуется, по умолчанию — Claude Haiku 5.5, самая дешёвая модель Claude):**
1. https://console.anthropic.com → регистрация. Anthropic официально не работает с Россией: нужны телефон и карта
   страны, где сервис доступен.
2. Billing → пополнить (от $5 — это примерно 8 000 писем).
3. API Keys → Create Key → скопировать `sk-ant-…` (показывается один раз).

**DeepSeek:** https://platform.deepseek.com → пополнить → API Keys → `sk-…`.

**Своя модель** («Настройки → Своя модель») — любой OpenAI-совместимый API:

| Где | Адрес API | Пример модели |
|---|---|---|
| Ollama на компьютере в домашней сети | `http://192.168.1.10:11434/v1` (IP компьютера) | `qwen2.5:7b`, `gemma3:12b` |
| LM Studio на компьютере | `http://192.168.1.10:1234/v1` | как названа в LM Studio |
| Ollama в Termux на самом телефоне | `http://127.0.0.1:11434/v1` | `qwen2.5:3b` |
| OpenRouter / Groq / Mistral / Gemini | адрес их OpenAI-совместимого API | по их документации |

Для локальной модели ключ не нужен, цены — 0. Какие модели подойдут: **Qwen2.5 / Qwen3 7–14B** (лучший русский
и JSON среди небольших), Gemma 3 12B, Mistral Nemo 12B, T-lite. На телефоне реально только 3–4B: письма пишут
сносно, но агентом управляют медленно и с ошибками — лучше держать модель на компьютере.

**Порядок и стратегия** («Настройки → Нейросеть»):
- «Порядок провайдеров»: `claude,deepseek,custom` — первый основной, остальные запасные.
  Если указан адрес своей модели, она добавляется в конец автоматически.
- «Стратегия»: `fallback` — всегда первый, запасные только при сбое; `round_robin` — по очереди.

PDF резюме читает только Claude. Без него резюме берётся из профиля hh или вставляется текстом.

## 8. Расходы и бюджет

- Строка на главном экране: запросы, токены и деньги за сегодня и за 30 дней.
- **«💰 Расходы»:** разбивка по дням и моделям за 14 дней, итоги за 7 и 30 дней.
- **«Дневной бюджет на нейросеть»** («Настройки → Нейросеть», по умолчанию $1). При превышении агент
  останавливается и присылает уведомление.

Ориентиры для Claude Haiku: одно письмо ≈ $0.0006; полный отклик агентом (письмо + 5–15 шагов) ≈ $0.005–0.02.
Суммы — оценка по ответам API, точная — в кабинете провайдера.

## 9. Резюме

Источники текста резюме (по приоритету):
1. **Профиль hh** — агент импортирует сам при первом запуске. Язык определяется по тексту резюме.
2. **PDF** — кнопки «PDF резюме RU / EN», текст извлекает Claude. Файл также прикрепляется к анкетам на сайтах,
   когда агент или вы нажимаете на поле загрузки.
3. **Вручную** — «Настройки → Резюме».

Для писем на английском нужно английское резюме: создайте его на hh.ru или загрузите PDF EN.
Имя для подписи берётся из «Профиля для анкет», а если он пуст — из резюме.

## 10. Журнал откликов

«Журнал» → раздел:
- все;
- отправленные;
- пробные (письма без отправки);
- ждут анкету;
- пропущенные и ошибки.

В каждой записи: компания, статус, откуда (hh через сайт, LinkedIn, Хабр…), язык, дата, **текст письма**,
кнопки «Открыть вакансию» и «Копировать письмо».

## 11. Расписание: ежедневный автозапуск

«Настройки → Запуск → Откликаться автоматически каждый день» + час запуска. В это время приложение само:
1. откликается через API hh (если подключено);
2. собирает вакансии с других площадок;
3. запускает агента hh (если hh работает через сайт или есть анкеты);
4. запускает агента LinkedIn (если включено в его настройках).

Работает при выключенном экране. Отключите экономию батареи ([раздел 1](#1-установка-и-обновление)).

## 12. Отклик через официальный API hh (необязательно)

API работает быстрее и в фоне без браузера, но hh должен одобрить приложение.

1. https://dev.hh.ru → «Мои приложения» → «Создать». Redirect URI: `https://localhost/hh-autoapply`.
2. После одобрения: «Настройки → hh.ru API» → Client ID, Client Secret, ваш email.
3. «Войти через API hh» → разрешить → «Мои резюме на hh» → выбрать RU и EN.

«Настройки → hh.ru: режим работы»: `auto` (API, если подключено, иначе агент через сайт), `api` или `site`.

## 14. Риски и правила площадок

- Массовые автоматические отклики противоречат правилам hh и особенно LinkedIn — аккаунт могут ограничить.
  Держите разумные лимиты и паузы.
- Капчу агент не решает — это защита от ботов. Он ждёт вас.
- Агент никогда не вводит пароли, коды из SMS, номера карт и паспортные данные — просит вас.
- Ключи нейросетей хранятся только на телефоне.

## 15. Частые проблемы

| Проблема | Решение |
|---|---|
| «Приложение не установлено, конфликтует с пакетом» | Удалить старую версию и поставить заново (один раз) |
| «Не настроена ни одна нейросеть» | Вставить ключ в «Быстром старте» или настроить «Свою модель» |
| Claude: 401 / ошибка баланса | Проверить ключ / пополнить Billing |
| Агент «топчется» на странице | Открыть пульт агента, посмотреть страницу, помочь или «Пропустить» |
| Агент просит войти | Войти прямо в окне агента → «Готово» |
| Не находит вакансий | Проверить запросы и фильтры в «Настройки → Поиск»; убрать лишние исключения |
| Ежедневный запуск не срабатывает | Снять ограничения батареи для приложения |
| «Дневной бюджет исчерпан» | Увеличить бюджет или продолжить завтра |

## 16. Для разработчика: сборка APK

APK собирает GitHub Actions (`.github/workflows/hh-autoapply-apk.yml`) при каждом пуше в `android/` и публикует
в релиз `hh-autoapply-latest`.

Ключ подписи — постоянный: берётся из секретов репозитория `HH_KEYSTORE_B64` (keystore в base64) и
`HH_KEYSTORE_PASSWORD`, а если их нет — создаётся один раз и хранится в кэше GitHub Actions. Кэш очищается
после 7 дней без сборок; чтобы ключ не потерялся никогда, добавьте его в секреты.

Локальная сборка: Android SDK + `gradle assembleDebug` в папке `android/`.
