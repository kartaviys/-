# HH Автоотклик для Android

## Установка

Скачайте APK на телефон и откройте файл:
https://github.com/kartaviyukr/-/releases/download/hh-autoapply-latest/hh-autoapply.apk

Android попросит разрешить установку из этого источника: разрешите. APK собирается
автоматически (GitHub Actions, workflow «HH Автоотклик APK») при каждом пуше в `android/`.

## Первая настройка (по порядку)

1. **Настройки → Нейросеть**: вставьте ключ Claude (`sk-ant-…`, берётся на console.anthropic.com).
   По умолчанию используется дешёвая модель `claude-haiku-5-5`. Ключ DeepSeek можно добавить как запасной.
2. **Настройки → hh.ru API**: Client ID, Client Secret и Redirect URI вашего приложения с https://dev.hh.ru/admin.
   В приложении на dev.hh.ru укажите тот же Redirect URI (по умолчанию `https://localhost/hh-autoapply`).
3. Кнопка **«Войти через API hh»**: разрешите доступ, и токен сохранится.
4. Кнопка **«Мои резюме на hh»**: выберите резюме для русских, а затем для английских вакансий.
5. Кнопки **«PDF резюме RU / EN»**: выберите файлы. Claude один раз прочитает их в текст для писем,
   а PDF будет прикрепляться к анкетам на сайтах работодателей.
6. Кнопка **«Войти на hh.ru (для тестов)»**: войдите в аккаунт во встроенном браузере.
7. **Настройки → Профиль**: имя, почта, телефон для анкет.

## Работа

- **«Журнал»**: все отклики с фильтрами (отправленные, пробные, ждут анкету, ошибки), текстом письма и ссылкой на вакансию.
- **«Пробный прогон»**: находит вакансии и пишет письма, но ничего не отправляет. Письма видны в логе и в «Журнале».
- **«Откликнуться»**: настоящие отклики через API hh. Работает в фоне, даже при выключенном экране.
- Вакансии с **тестом** или откликом **на сайте работодателя** попадают в очередь **«Анкеты»**.
  Там встроенный браузер открывает форму, и нейросеть заполняет поля. На вопросы о зарплате всегда
  ставится значение из настроек (25000). Резюме прикрепляется при тапе на поле загрузки файла.
  Проверьте анкету, отправьте её и нажмите «Отправлено ✓».
- **Настройки → «Откликаться автоматически каждый день»** включает ежедневный запуск в заданный час.

## Источники вакансий

Кнопка **«Источники вакансий»** на главном экране открывает список площадок. У каждой есть переключатель «вкл/выкл»,
кнопка **«Инструкция»** (как подключить) и **«Открыть»**.

- 🤖 **hh.ru** — поиск и отклик полностью автоматически через API.
- 📥 **Авто-сбор** (Хабр Карьера, GetMatch, Trudvsem, Telegram-каналы, Hacker News «Who is hiring», Remote OK,
  We Work Remotely, Remotive, Himalayas) — вакансии собираются при каждом запуске, письмо пишется заранее,
  вакансия попадает в «Анкеты». Там встроенный браузер открывает её, ИИ заполняет форму, вы подтверждаете.
- 🧭 **С подтверждением** (LinkedIn, Indeed, Glassdoor, Levels.fyi, Built In, Dice, Wellfound, Welcome to the Jungle,
  aijobs.net, Arc.dev, Turing, EURES, StepStone, XING, Relocate.me, Landing.jobs, Indeed Italia, InfoJobs.it, SuperJob,
  Работа.ру, Авито Работа, Сетка, GeekJob, ODS, карьерные сайты компаний) — у этих площадок нет открытого API или
  автоматизация запрещена их правилами. «Открыть» → вакансия → **«Отклик с ИИ»**: нейросеть читает вакансию, пишет
  письмо (копирует его) и заполняет форму; вы проверяете, отправляете и жмёте **«В журнал ✓»**.

Запросы для российских и зарубежных площадок, список Telegram-каналов и карьерных сайтов — в
«Настройки → Источники (кроме hh)».
