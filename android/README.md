# HH Автоотклик — Android-приложение

Автоматические отклики на вакансии Data Scientist / ML / AI / NLP / Data Analyst: hh.ru, Хабр Карьера, LinkedIn
и ещё 23 сайта (SuperJob, карьерные сайты российских компаний, США, ОАЭ, Европа). У каждого сайта — свой
**браузерный агент**: он сам ищет вакансии, отсеивает неподходящие, пишет живое сопроводительное письмо под
конкретную вакансию (на русском или английском — по языку вакансии) и откликается. Всё ведётся в журнале,
расходы на нейросеть считаются.

**Скачать APK:** https://github.com/kartaviys/-/releases/download/hh-autoapply-latest/hh-autoapply.apk

## 1. Установка и обновление

1. Откройте на телефоне ссылку на APK (выше) и скачайте файл.
2. Откройте файл → Android попросит разрешить установку из этого источника → «Настройки» → включить → назад → «Установить».
3. При первом запуске разрешите уведомления — через них приходят итоги и просьбы о помощи (капча, вход).
4. **Отключите экономию батареи** для приложения, иначе Android может усыплять фоновую работу:
   «Настройки телефона → Приложения → HH Автоотклик → Батарея → Без ограничений».

**Обновление.** Новые версии публикуются по той же ссылке и ставятся **поверх старой** — входы на сайты, настройки и
журнал сохраняются (все сборки подписаны одним ключом). Если Android пишет «конфликтует с другим пакетом» — у вас
очень старая версия: удалите её один раз и поставьте заново.

## 2. Быстрый старт

1. **«1. Ключ нейросети»** — вставьте ключ Claude (`sk-ant-…`) или DeepSeek (`sk-…`) → «Сохранить ключ».
   Где взять — [раздел 12](#12-нейросеть-claude-deepseek-своя-модель).
2. **«Войти на hh.ru»** (и/или Хабр, LinkedIn, другие сайты) → войдите в аккаунт → «Готово». Вход запоминается.
3. **«🤖 Агент hh»** → проверьте список «Что искать» → **«Старт»**.

Совет для первого раза: поставьте **лимит 3–5** и посмотрите, как агент работает, — и загляните в
«Журнал → Пропущенные», правильно ли он отсеивает вакансии.

## 4. Как агент выбирает вакансии

Одинаково для всех агентов (hh, Хабр, LinkedIn и 23 сайтов).

1. **Что искать** — ваш список запросов на экране агента, по одному на строку. Ищется **по названию вакансии**,
   без фильтров по региону, опыту и дате (на hh; у LinkedIn — свои настройки, [раздел 9](#9-агент-linkedin)).
2. **Все страницы.** По каждому запросу агент проходит страницы результатов 1, 2, 3… и на каждой сразу откликается,
   пока не кончатся страницы или не наберётся лимит. Если сайт повторяет последнюю страницу — переходит к следующему запросу.
3. **Уже откликались — не трогает.** Вакансии с отметкой «Вы откликнулись» / «Applied» прямо в выдаче не открываются;
   на странице вакансии отклик проверяется **до** написания письма; свои отклики приложение помнит. Такие вакансии
   не считаются новыми откликами и не тратят лимит. Неудачную попытку повторяет не раньше чем через 3 дня.
4. **Фильтр по названию** («Настройки → Поиск»): отсекаются junior/стажёры, lead/head, компьютерное зрение (CV),
   Data Engineer / инженер данных, DWH/ETL, BI, бизнес- и системные аналитики, DevOps/MLOps, backend/frontend, QA.
5. **Проверка нейросетью «подходит ли».** Перед письмом модель читает вакансию и сверяет её **суть** с полем
   «Какие вакансии мне подходят». Например, «Data Engineer, который немного делает ML» — не подходит.
   Причина пропуска видна в «Журнал → Пропущенные и ошибки». Стоит ≈ $0.0002 за вакансию.
6. **Письмо** — под конкретную вакансию, по фактам из резюме; язык — по языку вакансии.
7. **Отклик** — агент жмёт «Откликнуться», выбирает резюме нужного языка, вставляет письмо, отвечает на вопросы
   анкеты по резюме, на любой вопрос о зарплате пишет **250 000**, прикрепляет PDF резюме, отправляет.

## 5. Пульт агента

Открывается кнопкой «🤖 Агент …».

- **✏️ Что искать и лимит** — список запросов (у каждого агента свой, редактируется) и лимит откликов за сессию.
  Панель сама сворачивается, когда агент запущен или просит помощи, — браузер на весь экран.
- **Старт / Стоп.** Одновременно работает один агент. Если работает другой, кнопка покажет
  «Остановить X и запустить Y».
- **Окно браузера** — видно, что делает агент.
- **Готово / Пропустить** — когда агент просит помощи.

**Работает в фоне.** Можно свернуть приложение и выключить экран — в шторке висит уведомление с текущим действием.
Лучше запускать на зарядке.

**Капча.** Автопроверки вида «Checking your browser» агент пережидает сам. Настоящую капчу решаете вы: придёт
громкое уведомление «Агенту нужна помощь» → тап → решите капчу → агент **продолжит сам**, как только она исчезнет.
Так же — со входом в аккаунт и кодами из SMS. Если 15 минут никто не ответил, вакансия пропускается.

**Подтверждение перед отправкой** — по умолчанию выключено (агент отправляет сам), у LinkedIn — включено.
Настраивается: «Настройки → Браузерный агент» и «Настройки → LinkedIn-агент».

## 6. Агент hh

1. «Войти на hh.ru» → войдите → «Готово».
2. «🤖 Агент hh» → «Старт».

Порядок: проверяет вход → при первом запуске импортирует ваши резюме из профиля hh (если тексты не заданы) →
**рекомендованные hh вакансии** под каждое резюме → **ваш список «Что искать»** (все страницы) → очередь «Анкеты»
с других площадок ([раздел 11](#11-другие-площадки-и-анкеты)).

Лимиты: 50 за сессию (поле на пульте), 150 откликов в сутки на всё приложение («Настройки → Запуск»).
Официальный API hh не нужен ([раздел 17](#17-официальный-api-hh-необязательно) — если всё же хотите).

## 7. Агент Хабр Карьеры

1. «Войти на Хабр Карьеру» → кнопка «Войти» вверху страницы → войдите → «Готово». Нужен заполненный профиль на Хабр Карьере.
2. «🤖 Агент Хабр» → «Старт».

Ищет через поиск Хабра, оставляет вакансии, где **слова запроса есть в названии**, проходит все страницы, открывает
вакансию, пишет письмо, жмёт «Откликнуться» и отправляет. Пропускает junior и вакансии с откликом «на сайте компании».
Лимиты: 30 за сессию, 60 в сутки («Настройки → Хабр Карьера — агент»).

## 8. ODS — сохранять вакансии

«Обновить вакансии ODS» читает канал **ODS #jobs** (t.me/odsjobs) — при первом запуске около 200 последних постов,
дальше только новые — и **сохраняет** подходящие (по фильтру названия, без junior и CV). **Откликов и писем нет.**
«📌 Сохранённые» — список: название, компания/зарплата/формат, описание, кнопка «Открыть вакансию» (страница на ods.ai).
Они же — в «Журнал → Сохранённые ODS». В ежедневном автозапуске список обновляется сам.

**Контакты HR.** После обновления (или по кнопке «📇 Найти контакты HR») приложение открывает страницу каждой сохранённой
вакансии на ods.ai во встроенном браузере, при необходимости жмёт «Показать контакты» и сохраняет, что нашлось:
Telegram, email, телефон, LinkedIn, ссылку на отклик. Контакты пишутся в начало описания, вакансия в списке
помечается 📇, в карточке появляется кнопка **«Написать HR»** (открывает Telegram или почту). За раз — до 40 вакансий,
каждая проверяется один раз. Если ods.ai показывает контакты только после входа — приложение попросит нажать
**«Войти на ODS»** и войти своим аккаунтом (вход сохраняется). Пока работает агент, поиск контактов не запускается.
Ваши собственные email и Telegram из настроек в контакты не попадают.

## 9. Агент LinkedIn

1. «Войти в LinkedIn» → email и пароль (вход через Google в приложении не работает) → «Готово».
2. «🤖 Агент LinkedIn» → «Что искать» (свой список) → «Старт».

Порядок: **рекомендованные LinkedIn вакансии** (только с Easy Apply) → ваш список (поиск только Easy Apply, все
страницы). Каждую вакансию открывает, пишет письмо и проходит все шаги Easy Apply: контакты, резюме, вопросы, отправка.

Настройки («Настройки → LinkedIn-агент»): локация (пусто — весь мир; Germany, European Union, Italy…), только
удалёнка (по умолчанию да), только Mid-Senior (нет), вакансии за N дней (7), страниц на запрос.

**Осторожный режим по умолчанию** — LinkedIn запрещает автоматизацию и блокирует за неё аккаунты:
подтверждение перед каждой отправкой, 20 откликов за сессию, **30 в сутки**, пауза **45–120 секунд**.
Ослаблять — на свой риск.

**Белый экран / не грузится.** LinkedIn в РФ заблокирован: включите VPN **для всего телефона**. Если в VPN есть
«раздельное туннелирование» (выбор приложений) — добавьте в список «HH Автоотклик» (то, что работает приложение
LinkedIn, не значит, что VPN включён для нашего приложения). Затем «Обновить» на экране входа.

свой список «Что искать» и лимит.

| Группа | Агенты |

| Россия — сайты компаний | Авито ✅, Лаборатория Касперского ✅, Яндекс ⚠️, Сбер ⚠️, Т-Банк ⚠️, Ozon ⚠️, VK ⚠️, МТС ⚠️ |
| США | Dice ✅, Built In ✅, Wellfound ✅, Indeed ⚠️, Glassdoor ⚠️ |
| ОАЭ | Bayt ✅, Naukrigulf ⚠️, GulfTalent ⚠️, Indeed ОАЭ ⚠️ |
| Европа и релокация | Relocate.me ✅, StepStone ⚠️ |

- ✅ — формат ссылок на вакансии проверен на реальной выдаче.
- ⚠️ — проверить заранее не удалось (сайт не открылся с проверочного сервера в США). Если агент не найдёт ссылки на
  вакансии по шаблону, их **выберет нейросеть** из ссылок страницы.
- **Сайты компаний** (Авито, Касперский, Relocate.me): поиск по запросу там не работает — агент берёт всю ленту
  вакансий и сам отбирает подходящие.
- **Т-Банк** работает на российском сертификате: если сайт не открывается, установите в телефон сертификат Минцифры.
- **Indeed, Glassdoor, GulfTalent** под защитой Cloudflare — капча будет чаще.
- Отклик почти везде требует аккаунта — нажмите «Войти» один раз (или агент попросит, когда дойдёт до отклика).
- Лимит — **30 откликов в сутки на каждый сайт** («Настройки → Браузерный агент»), 20 за сессию (поле на пульте).

## 12. Нейросеть: Claude, DeepSeek, своя модель

Нужен хотя бы один вариант.

**Claude (рекомендуется; по умолчанию Claude Haiku 5.5 — самая дешёвая модель Claude):**
1. https://console.anthropic.com → регистрация. Anthropic официально не работает с Россией: нужны телефон и карта
   страны, где сервис доступен.
2. Billing → пополнить (от $5).
3. API Keys → Create Key → скопировать `sk-ant-…` (показывается один раз).

**DeepSeek:** https://platform.deepseek.com → пополнить → API Keys → `sk-…`.

**Своя модель** («Настройки → Своя модель») — любой OpenAI-совместимый API:

| Где | Адрес API | Пример модели |
|---|---|---|
| Ollama на компьютере в домашней сети | `http://192.168.1.10:11434/v1` (IP компьютера) | `qwen2.5:7b`, `gemma3:12b` |
| LM Studio на компьютере | `http://192.168.1.10:1234/v1` | как названа в LM Studio |
| Ollama в Termux на телефоне | `http://127.0.0.1:11434/v1` | `qwen2.5:3b` |
| OpenRouter / Groq / Mistral / Gemini | адрес их OpenAI-совместимого API | по их документации |

Какие модели подойдут: **Qwen2.5 / Qwen3 7–14B** (лучший русский и JSON среди небольших), Gemma 3 12B, Mistral Nemo 12B,
T-lite. На телефоне реально только 3–4B: письма пишут сносно, но агентом управляют медленно и с ошибками.

**Порядок и стратегия** («Настройки → Нейросеть»): «Порядок провайдеров» `claude,deepseek,custom` — первый основной,
остальные запасные (своя модель с указанным адресом добавляется в конец сама); «Стратегия» `fallback` — всегда первый,
`round_robin` — по очереди. PDF резюме читает только Claude.

## 13. Расходы и бюджет

- Строка на главном экране: запросы, токены и деньги за сегодня и за 30 дней.
- **«💰 Расходы»** — по дням и моделям за 14 дней, итоги за 7 и 30 дней.
- **«Дневной бюджет на нейросеть»** («Настройки → Нейросеть», по умолчанию $1) — при превышении агент останавливается
  и присылает уведомление.

Ориентиры для Claude Haiku: проверка «подходит ли» ≈ $0.0002, письмо ≈ $0.0006, полный отклик агентом
(письмо + 5–15 шагов) ≈ $0.005–0.02. Суммы — оценка по ответам API, точная — в кабинете провайдера.

## 14. Резюме

Откуда берётся текст резюме (по приоритету):
1. **Профиль hh** — агент hh импортирует названия и тексты резюме сам при первом запуске; язык — по тексту.
2. **PDF** — «▸ Дополнительно → PDF резюме RU / EN», текст извлекает Claude. Файл прикрепляется к анкетам на сайтах.
3. **Вручную** — «Настройки → Резюме».

Для писем на английском нужно английское резюме — создайте его на hh.ru или загрузите PDF EN.
Имя для подписи — из «Профиля для анкет», а если он пуст — из резюме.

## 15. Журнал

«Журнал» → раздел: все · отправленные · пробные (письма без отправки) · ждут анкету · сохранённые ODS ·
пропущенные и ошибки. В записи: компания, статус, откуда (hh через сайт, Хабр, LinkedIn, SuperJob…), язык, дата,
**текст письма** или причина пропуска («не подходит: …», «откликались ранее»), «Открыть вакансию», «Копировать письмо».

## 16. Ежедневный автозапуск

«Настройки → Запуск → Откликаться автоматически каждый день» + час. В это время приложение само:
1. откликается через API hh (если подключено, [раздел 17](#17-официальный-api-hh-необязательно));
2. собирает вакансии с площадок авто-сбора ([раздел 11](#11-другие-площадки-и-анкеты));
3. обновляет сохранённые вакансии ODS;
4. запускает агента hh (если hh работает через сайт или есть анкеты);
5. запускает агентов Хабра и LinkedIn — если включено в их настройках.

Работает при выключенном экране. Не забудьте снять ограничения батареи ([раздел 1](#1-установка-и-обновление)).

## 17. Официальный API hh (необязательно)

API работает быстрее и в фоне без браузера, но hh должен одобрить приложение.

1. https://dev.hh.ru → «Мои приложения» → «Создать». Redirect URI: `https://localhost/hh-autoapply`.
2. После одобрения: «Настройки → hh.ru API» → Client ID, Client Secret, ваш email.
3. «▸ Дополнительно → Войти через API hh» → разрешить → «Мои резюме на hh» → выбрать RU и EN.

«Настройки → hh.ru: режим работы»: `auto` (API, если подключено, иначе агент через сайт), `api` или `site`.

## 19. Риски и правила площадок

- Массовые автоматические отклики противоречат правилам hh и особенно LinkedIn — аккаунт могут ограничить.
  Держите разумные лимиты и паузы.
- Капчу агент не решает — это защита от ботов. Он ждёт вас и продолжает сам.
- Агент никогда не вводит пароли, коды из SMS, номера карт и паспортные данные — просит вас.
- Ключи нейросетей хранятся только на телефоне.

## 20. Частые проблемы

| Проблема | Решение |
|---|---|
| «Приложение не установлено, конфликтует с пакетом» | Удалить старую версию и поставить заново (один раз) |
| LinkedIn — белый экран | VPN для всего телефона или добавить «HH Автоотклик» в приложения VPN → «Обновить» ([раздел 9](#9-агент-linkedin)) |
| «Агент LinkedIn» показывает hh | Работает агент hh — нажмите «Остановить hh и запустить LinkedIn» |
| Агент откликается не туда | Поправьте «Какие вакансии мне подходят» и «Исключить» в «Настройки → Поиск»; причины — в «Журнал → Пропущенные» |
| Агент не находит вакансии на сайте ⚠️ | Откройте пульт, посмотрите страницу; попробуйте другой запрос; пришлите скриншот разработчику |
| «Не настроена ни одна нейросеть» | Вставить ключ в блок 1 или настроить «Свою модель» |
| Claude: 401 / ошибка баланса | Проверить ключ / пополнить Billing |
| Агент просит войти | Войти прямо в окне агента → «Готово» |
| Т-Банк не открывается | Установить в телефон сертификат Минцифры |
| Ежедневный запуск не срабатывает | Снять ограничения батареи для приложения |
| «Дневной бюджет исчерпан» | Увеличить бюджет или продолжить завтра |

## 21. Для разработчика

**Сборка.** APK собирает GitHub Actions (`.github/workflows/hh-autoapply-apk.yml`) при каждом пуше в `android/`
и публикует в релиз `hh-autoapply-latest`. Локально: Android SDK + `gradle assembleDebug` в папке `android/`.

**Подпись.** Ключ постоянный: из секретов репозитория `HH_KEYSTORE_B64` (keystore в base64) и `HH_KEYSTORE_PASSWORD`,
а если их нет — создаётся один раз и хранится в кэше GitHub Actions (кэш очищается после 7 дней без сборок —
чтобы не потерять ключ, положите его в секреты).
