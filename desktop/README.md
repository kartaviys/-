# HH Автоотклик для Windows и macOS (+ пульт с iPhone)

Те же агенты, что в Android-приложении: **hh.ru, Хабр Карьера, LinkedIn и ещё 23 сайта** (SuperJob, GeekJob, Работа.ру,
GetMatch, сайты Яндекса, Сбера, Т-Банка, Ozon, VK, Авито, МТС, Касперского, Dice, Built In, Wellfound, Indeed, Glassdoor,
Bayt, Naukrigulf, GulfTalent, Indeed ОАЭ, StepStone, Relocate.me). Агент управляет настоящим **Chrome/Edge** на вашем
компьютере: ищет вакансии, отсеивает неподходящие (фильтр названий + проверка нейросетью), пишет письмо под вакансию
и откликается. С **iPhone** (или любого телефона) можно управлять агентами через Safari — по Wi-Fi.

| Система | Файл |

| Windows 10/11 | https://github.com/kartaviys/-/releases/download/hh-autoapply-desktop-latest/hh-autoapply-windows-setup.exe |
| macOS (Apple Silicon и Intel) | https://github.com/kartaviys/-/releases/download/hh-autoapply-desktop-latest/hh-autoapply-macos.dmg |

Нужен установленный **Google Chrome** (на Windows подойдёт и встроенный Edge).

**Первый запуск — предупреждения системы** (приложение не подписано платным сертификатом):
- **Windows:** «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** откройте dmg, перетащите «HH Autoapply» в «Программы». При первом запуске: правый клик по приложению →
  «Открыть» → «Открыть». Если macOS пишет «повреждено» — «Системные настройки → Конфиденциальность и безопасность →
  Всё равно открыть», либо в Терминале: `xattr -cr "/Applications/HH Autoapply.app"`.

## Быстрый старт

1. Откройте приложение → **«Настройки»** → вставьте ключ **Claude** (`sk-ant-…`) или **DeepSeek** → «Сохранить».
   Claude не работает из России напрямую — нужен VPN на компьютере (иначе ошибка 403); DeepSeek работает без VPN.
2. Вкладка **«Агенты»** → у нужного сайта **«Войти»** → откроется окно Chrome → войдите в аккаунт. Вход запоминается
   (у приложения свой профиль браузера, ваш обычный Chrome не затрагивается).
3. **«✏️ Что искать»** — свой список вакансий у каждого агента (по одной на строку) и **лимит** → **«▶ Старт»**.

Агент работает в окне Chrome — видно каждое действие. Капчу и вход решаете прямо в этом окне: придёт уведомление,
агент продолжит сам, как только капча исчезнет. Компьютер не должен засыпать (настройки питания).

## Как агент выбирает вакансии

1. Ищет по вашему списку **по названию вакансии**, проходит **все страницы** результатов.
2. Пропускает вакансии, где вы уже откликались (отметка «Вы откликнулись» / «Applied»), и уже обработанные.
3. Фильтр по названию: отсекаются junior/стажёры, head/руководители, компьютерное зрение, Data Engineer, DWH/ETL, BI,
   бизнес- и системные аналитики, DevOps/MLOps, frontend/fullstack, тестировщики.
4. Нейросеть читает вакансию и проверяет, подходит ли она под **«Какие вакансии мне подходят»** (по умолчанию —
   откликаться; отклоняет, только если основная работа явно не ваша).
5. Пишет письмо по фактам из резюме (язык — по языку вакансии), откликается: резюме нужного языка, письмо, ответы на
   вопросы, на любой вопрос о зарплате — **250 000**, прикрепляет PDF резюме.

hh: рекомендованные hh вакансии под ваши резюме и ваш список — по кругу, по 30 вакансий на каждый (настройка «hh: вакансий подряд»). LinkedIn: сначала рекомендованные
(только Easy Apply), потом поиск Easy Apply; по умолчанию спрашивает подтверждение перед отправкой и не больше 30 в сутки.

## 📱 Пульт с iPhone

1. На компьютере: «Настройки → Пульт с телефона → Разрешить… = `true`» → «Сохранить» → перезапустите приложение.
2. Вкладка **«📱 Пульт с телефона»** покажет адрес вида `http://192.168.1.5:8765/?pin=123456`.
3. Откройте его в Safari на iPhone (телефон и компьютер — в одной Wi-Fi сети). «Поделиться → На экран „Домой“» —
   пульт будет как приложение.

С телефона можно: запускать/останавливать агентов, менять «Что искать» и лимиты, смотреть статус, журнал и расходы,
отвечать «Готово / Пропустить» и смотреть снимок страницы. Решать капчу и входить в аккаунты — на компьютере.

**Уведомления на iPhone:** «Настройки → Уведомления в Telegram»: создайте бота у @BotFather, вставьте токен и свой
chat id (узнать у @userinfobot) — капча, подтверждения и итоги будут приходить в Telegram.

## Другое

- **Резюме:** «Настройки → Резюме в PDF» (текст достанет Claude) или агент hh сам импортирует резюме из профиля hh.
- **Своя модель:** «Настройки → Своя модель» — Ollama/LM Studio на этом же компьютере (`http://127.0.0.1:11434/v1`)
  или любой OpenAI-совместимый API. Локальная модель 7–14B (Qwen2.5/Qwen3) справляется с письмами и проверкой;
  для управления браузером надёжнее Claude/DeepSeek.
- **Скорость:** вкладка «⏱ Скорость» показывает время отклика по каждому ресурсу (среднее, минимум, максимум, откликов в час) за сегодня, 7 и 30 дней. Время последнего и среднего отклика видно и в строке статуса.
- **Расходы:** вкладка «💰 Расходы» и «Дневной бюджет» (по умолчанию $1) — при превышении агент останавливается.
- **Расписание:** «Настройки → Расписание» — каждый день в ЧЧ:ММ запускать агентов по очереди (пока приложение открыто).
- **Данные** (настройки, журнал, профиль браузера) хранятся в папке приложения:
  Windows `%APPDATA%\HH Autoapply`, macOS `~/Library/Application Support/HH Autoapply`.

Чем отличается от Android-версии: нет площадок авто-сбора (Telegram-каналы, Hacker News, удалёнка), очереди «Анкеты»,
ODS и официального API hh — только агенты сайтов. Правила площадок и риски — те же, см. [Android README](../android/README.md#19-риски-и-правила-площадок).

## Для разработчика

```bash
cd desktop
```

```bash
npm install
```

```bash
npm start
```

- `npm run server` — запуск без Electron: пульт на http://127.0.0.1:8765 .
- `HH_HEADLESS=1 npm test` — сквозной тест на поддельном сайте и поддельной нейросети.
- `npm run dist:win` / `npm run dist:mac` — сборка установщиков; в CI — `.github/workflows/hh-autoapply-desktop.yml`,
  релиз `hh-autoapply-desktop-latest`.
- `assets/agent.js` при сборке копируется из Android (`android/app/src/main/assets/agent.js`) — один общий файл.

| Файл | Что внутри |
|---|---|
| `main.js` | Окно Electron и системные уведомления |
| `src/app.js` | Сборка: хранилище, агент, сервер пульта, Telegram, расписание |
| `src/agent.js` | Агент: Chrome через Playwright, цикл «снимок → решение → действие», сессии hh / Хабр / LinkedIn / сайтов |
| `src/sites.js` | Описания 23 сайтов |
| `src/server.js` | API и раздача пульта (локально и по Wi-Fi с PIN) |
| `src/llm.js`, `src/letters.js` | Claude / DeepSeek / своя модель, письма, проверка «подходит ли» |
| `src/store.js`, `src/text.js` | Настройки, журнал, расходы; фильтры и определение языка |
| `ui/index.html` | Интерфейс пульта (компьютер и телефон) |
